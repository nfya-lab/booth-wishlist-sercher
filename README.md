# BOOTH スキリスト検索・ソート

BOOTH の「スキした商品」ページ(スキリスト)に検索・絞り込み・ソート機能を追加する Chrome 拡張機能 / ブックマークレットです。

## 機能

- キーワード検索(商品名・ショップ名・カテゴリ・タグ)/ 除外キーワード
- タグ絞り込み(入力補完つき)・カテゴリ / サブカテゴリ・イベント・価格帯・年齢制限・在庫での絞り込み
- 価格 / スキ数 / 商品名でのソート
- 表示列数・表示件数の変更
- スキの管理(複数選択してリストへ追加・スキ解除)— BOOTH 標準と同じ UI
- 共有スキリスト(`booth.pm/wish_list_names/...`)でも検索・絞り込みが利用可能
- 読み込み中も検索可能(読み込んだ分から順次表示)・24時間キャッシュで2回目以降は即表示

## インストール

### Chrome 拡張機能

1. このリポジトリをダウンロード(Code → Download ZIP)して展開
2. `chrome://extensions/` を開き「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」で展開したフォルダを選択

### ブックマークレット(スマホ・他ブラウザ向け)

[こちらのページ](https://nfya-lab.github.io/booth-wishlist-sercher/)の手順でブックマークに登録してください。

## 開発

`content.js` / `content.css` が拡張機能の本体です。ブックマークレット(`docs/bookmarklet.js` / `docs/bookmarklet.css`)は手で編集せず、以下で生成します:

```
node scripts/build-bookmarklet.js
```
